# 整体框架

```
                    qmake 主程序
                         │
                         │ 加载业务插件
                         ↓
               Plugin_Inspect_Color
                         │
                         │ genWidget()
                         ↓
              Widget_Inspect_Color
                         │
                         │ 调用
                         ↓
             QtImageControlPlugin
                    （通用 DLL）
                         │
       ┌─────────────────┼─────────────────┐
       │                 │                 │
       ↓                 ↓                 ↓
   图像显示           图像交互           图像数据
       │                 │                 │
       ↓                 ↓                 ↓
 QGraphicsView      Mouse/Tool          QImage
 QGraphicsScene     ROI                 ImageData
 QGraphicsItem      Rotate
                    Color
                    Paint
                    Template
                    Contour
```
`QtImageControlPlugin` 不创建 `Widget_Inspect_Color`,

````
Plugin_Inspect_ComPlugin/
│
├── Plugin_Inspect_ComPlugin.pro
│
├── include/
│   └── Plugin_Inspect_ComPlugin/
│       │
│       ├── Plugin_Inspect_ComPlugin.h          // 插件导入
│       ├── Plugin_Inspect_ComPluginGlobal.h   // 插件定义
│       ├── Common.h                            // 公共类名/公共定义
│       │
│       ├── Image.h                             // 图像显示
│       ├── ImageROI.h                           // 检测范围设定: 外部矩形，矩形，多边形，圆形
│       ├── ImageTransform.h 										// 旋转操作
│       ├── ImageColor.h                         // 取色操作
│       ├── ImagePaint.h                         // 取色操作
│       ├── ImageTemplate.h                      // 模板匹配，图案编辑
│       └── ImageContour.h                       // 匹配轮廓编辑&跟随
│
├── src/
│   │
│   ├── Plugin_Inspect_ComPlugin.cpp
│   │
│   ├── Image.cpp
│   ├── ImageROI.cpp
│   ├── ImageTransform.cpp 											// ROI旋转及图像变换
│   ├── ImageColor.cpp
│   ├── ImagePaint.h                         // 取色操作
│   ├── ImageTemplate.cpp
│   └── ImageContour.cpp
│
└── README.md
````
