# 整体框架

```
                    qmake 主程序
                         │
                         │ 加载业务插件
                         ↓
               Plugin_Inspect_Color
                         │
                         │ genWidget()
                         ↓
              Widget_Inspect_Color
                         │
                         │ 调用
                         ↓
             QtImageControlPlugin
                    （通用 DLL）
                         │
       ┌─────────────────┼─────────────────┐
       │                 │                 │
       ↓                 ↓                 ↓
   图像显示           图像交互           图像数据
       │                 │                 │
       ↓                 ↓                 ↓
 QGraphicsView      Mouse/Tool          QImage
 QGraphicsScene     ROI                 ImageData
 QGraphicsItem      Rotate
                    Color
                    Paint
                    Template
                    Contour
```
Plugin_Inspect_CommonControl图像编辑功能公共插件

````
Plugin_Inspect_CommonControl/
│
├── Plugin_Inspect_CommonControl.pro
│
├── include/
│   └── Plugin_Inspect_CommonControl/
│       │
│       ├── Plugin_Inspect_ComPlugin.h          // 插件导入
│       ├── Plugin_Inspect_ComPluginGlobal.h    // 插件定义
│       ├── Plugin_Common.h                     // 公共类名/公共定义
│       │
│       ├── Plugin_Image.h                    // 图像显示
│       ├── Plugin_ImageROI.h                 // 检测范围设定: 外部矩形，矩形，多边形，圆形
│       ├── Plugin_ImageTransform.h 					// 旋转操作
│       ├── Plugin_ImageColor.h               // 取色操作
│       ├── Plugin_ImagePaint.h               // 涂抹操作
│       ├── Plugin_ImageTemplate.h            // 模板匹配，图案编辑
│       └── Plugin_ImageContour.h             // 匹配轮廓编辑&跟随
│ 			│ 
│ 			├── GraphicsInterface 			// 操作接口层
│ 			├── GraphicsView.h 					// QGraphicsView 封装 
│ 			├── GraphicsScene.h 				// QGraphicsScene 封装 
│ 			└── GraphicsItem.h 					// QGraphicsItem 封装
│
├── src/
│   │
│   ├── Plugin_Inspect_CommonControl.cpp
│   │
│   ├── Plugin_Image.cpp																// 图像显示
│   ├── Plugin_ImageROI.cpp														  // 检测范围设定: 外部矩形，矩形，多边形，圆形
│   ├── Plugin_ImageTransform.cpp 											// 旋转操作
│   ├── Plugin_ImageColor.cpp                           // 取色操作
│   ├── Plugin_ImagePaint.cpp                           // 涂抹操作
│   ├── Plugin_ImageTemplate.cpp                        // 模板匹配，图案编辑
│   └── Plugin_ImageContour.cpp                         // 匹配轮廓编辑&跟随
│ 	│ 
│ 	├── GraphicsView.cpp 
│ 	├── GraphicsScene.cpp 
│ 	└── GraphicsItem.cpp
````
