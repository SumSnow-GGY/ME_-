# 整体框架

```
                    qmake 主程序
                         │
                         │ 加载业务插件
                         ↓
               Plugin_Inspect_Color
                         │
                         │ genWidget()
                         ↓
              Widget_Inspect_Color
                         │
                         │ 调用
                         ↓
             QtImageControlPlugin
                    （通用 DLL）
                         │
       ┌─────────────────┼─────────────────┐
       │                 │                 │
       ↓                 ↓                 ↓
   图像显示           图像交互           图像数据
       │                 │                 │
       ↓                 ↓                 ↓
 QGraphicsView      Mouse/Tool          QImage
 QGraphicsScene     ROI                 ImageData
 QGraphicsItem      Rotate
                    Color
                    Paint
                    Template
                    Contour
```

文件作用定义
---

`Plugin_Common.h`公共枚举、结构体、数据类型
	图像操作模式
	ROI 类型：矩形，多边形，圆形
	ROI 数据Mat
	Graphics Item 类型
	鼠标操作类型
	鼠标形状&大小参数
	鼠标悬停图像点坐标
	涂抹画笔参数


`GraphicsInterface.h`**统一操作接口**

`GraphicsView.h/.cpp`View、鼠标、缩放、平移

`GraphicsScene.h/.cpp`Scene、Item管理

`GraphicsItem.h/.cpp`所有自定义Item的基础类

`Plugin_Image.h/.cpp`图像显示
