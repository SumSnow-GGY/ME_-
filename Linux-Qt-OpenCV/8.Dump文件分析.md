


> Linux Crash Dump
**WinDbg 版本 ≥ 1.2402.24001.0**
# 0.准备文件
1. Core文件
2. ELF文件
3. 源码（查看代码）


## 文件放置
```cpp
D:\LinuxCore\
├── core.HIDCamera_Qt6.序号
├── HIDCamera_Qt6 [ELF文件]
└── HIDCamera\
    ├── mainwindow.cpp
    ├── mainwindow.h
    ├── main.cpp
    ├──....
```

# 1.运行Windbg
1.  `ctrl` + `D` 打开`core.HIDCamera_Qt6.序号`文件。

2. 设置 ELF 文件(HIDCamera_Qt6)路径`.sympath D:\LinuxCore`
![输入图片说明](/imgs/2026-08-21/1kztUjoaPDwiCYg2.png)

3. 重新加载`.reload`
![输入图片说明](/imgs/2026-08-21/qx2PJz1QMQCcA0po.png)
注：出现`HIDCamera_Qt6 (no symbols)`需检查ELF和Core是否统一生成。

4. 执行`!dumpdebug`确认 WinDbg 是否识别为 Linux ELF Core。
![输入图片说明](/imgs/2026-08-21/4045HBKNKGWfXori.png)
正常情况下应该能够看到类似：`ELF User Core`

5. 设置源码路径`.srcpath D:\LinuxCore\HIDCamera`
![输入图片说明](/imgs/2026-08-21/dClMx2I37ruTHT6j.png)
6. 重新加载`.reload`
