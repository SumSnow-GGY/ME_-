## OK/NG/扩展存图路径，磁盘分区

原始代码主要针对 Windows 系统设计，通过判断盘符（C盘、D盘）来避免存图路径与软件运行路径位于同一磁盘。
保持原有盘符判断

Windows判断方式：
```cpp
QString drive1 = info1.absolutePath().startsWith('/') ? "/" : info1.absolutePath().left(3);
QString drive2 = info2.absolutePath().startsWith('/') ? "/" : info2.absolutePath().left(3);
if(drive1 == drive2)
```
Linux系统没有Windows中的盘符（C盘、D盘）概念，文件路径统一以 `/` 开头，例如： 
```text 
/home/hid-kb/CameraTest_env/HIDCamera_Qt6_QMake/HIDCamera/Camera /home/hid-kb/project1/SaveImg_HIDCamera_Linux
```
系统盘
/dev/sda3
    └── HIDCamera程序
数据盘
/dev/sdb1
    └── OK/NG图片

使用Windows盘符判断逻辑导致所有路径都被认为属于同一个磁盘，产生误报警。
Linux判断方式：
```cpp
QString  systempath = QCoreApplication::applicationDirPath(); 
// 获取路径所在磁盘/分区  
QString  disk1 = getDiskDevice(folderPath); //获取磁盘路径

QString debug_save_image::getDiskDevice(QString path)
{
    QProcess process;
    process.start("df",QStringList() << "-P" << path);
    process.waitForFinished();
    QString output = process.readAllStandardOutput();
    QStringList lines = output.split("\n");
    if(lines.size() >= 2)
    {
        QString line = lines[1].simplified();
        QStringList cols = line.split(QRegularExpression("\\s+"));
        if(cols.size() > 0)
        {
            return cols[0];
        }
    }
    return "";
}
```

```cpp
// 禁用进程电源节流
void disablePowerThrottling() {
    // 检查是否支持 SetProcessInformation
    HMODULE hKernel32 = GetModuleHandleW(L"kernel32.dll");
    if (!hKernel32) return;

    auto pSetProcessInformation = reinterpret_cast<decltype(&SetProcessInformation)>(
                GetProcAddress(hKernel32, "SetProcessInformation")
                );
    if (!pSetProcessInformation) return;

    // 设置：禁用执行速度节流
    PROCESS_POWER_THROTTLING_STATE state = {0};
    state.Version = PROCESS_POWER_THROTTLING_CURRENT_VERSION;
    state.ControlMask = PROCESS_POWER_THROTTLING_EXECUTION_SPEED;
    state.StateMask = 0; // 0 = 禁用节流

    pSetProcessInformation(
                GetCurrentProcess(),
                ProcessPowerThrottling,
                &state,
                sizeof(state)
                );
}
```
