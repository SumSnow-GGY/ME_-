# Linux Qt6 创建项目问题记录（Ubuntu 22.04 + Qt6.10.3）

## 环境
-   Ubuntu 22.04.5 x86_64
-   Qt 6.10.3 gcc_64
-   GCC 11.4
-   CMake 3.30
-   Ninja
   
----------

# 1. Qt Creator DBus提示
## 现象
```
org.freedesktop.DBus.Error.ServiceUnknown
org.freedesktop.portal.Desktop was not provided
```
## 原因
缺少 Linux 桌面服务：
```
xdg-desktop-portal
```
## 处理
安装：
```bash
sudo apt install xdg-desktop-portal xdg-desktop-portal-gtk
```

备注：

该问题不影响 Qt 编译，可暂时忽略。

----------

# 2. Qt6Widgets无法找到

## 错误

```
Qt6Widgets could not be found
Qt6Gui could not be found
```

## 原因

Qt6依赖关系：

```
Qt6Widgets
    ↓
Qt6Gui
    ↓
OpenGL
```

实际问题：

```
OpenGL检测失败
```

----------

# 3. OpenGL检测失败

## 错误

```
Could NOT find OpenGL
```

## 检查

OpenGL库：

```bash
ls /usr/lib/x86_64-linux-gnu/libGL*
```

确认：

```
libGL.so
libGLX.so
libOpenGL.so
```

OpenGL头文件：

```bash
ls /usr/include/GL
```

确认：

```
gl.h
glx.h
```

----------

# 4. 解决：使用Qt自带CMake

## 原因

Ubuntu默认：

```
CMake 3.22
```

Qt6.10推荐：

```
CMake >= 3.25
```

旧版本CMake导致OpenGL识别失败。

## 解决

使用Qt自带CMake：

```bash
~/Qt/Tools/CMake/bin/cmake
```

重新配置：

```bash
cmake .. \
-DCMAKE_PREFIX_PATH=~/Qt/6.10.3/gcc_64
```

成功：

```
Found OpenGL

Configuring done
Generating done
```

----------

# 5. CMake缓存问题

## 现象

```
No CMake configuration for build type
```

## 原因

CMake失败后，build目录保存旧缓存。

## 解决

删除：

```bash
rm -rf build
```

重新 Configure。

----------

# 6. Qt Creator配置

Qt路径：

```
~/Qt/6.10.3/gcc_64
```

CMake：

```
~/Qt/Tools/CMake/bin/cmake
```

不要使用：

```
/usr/bin/cmake
```
