


# Qt6 Linux崩溃Dump机制迁移记录

 - Linux替代方案：
HIDCamera Qt6 Linux版本已完成 Windows `DbgHelp + MiniDump` 迁移，
使用  `Signal Handler + Core Dump + GDB` 方案。
```text
   signal异常捕获
        |
 backtrace获取调用栈
        |
 Linux Core Dump机制
        |
core.HIDCamera_Qt6.xxx
        |
     GDB分析
```
# 1. Linux异常捕获代码修改

## 1.1 增加头文件

修改：
```cpp
#ifdef _WIN32
	#include <windows.h>
	#include <DbgHelp.h>
#else
	#include <signal.h>
	#include <execinfo.h>
	#include <unistd.h>
#endif
```
----------
## 1.2 Linux  ApplicationCrashHandler函数
新增：
```cpp
#ifndef _WIN32
void ApplicationCrashHandler(int sig)
{
    void *buffer[50];
    int size = backtrace(buffer,50);
    char **symbols = backtrace_symbols(buffer,size);
    printf("========== Application Crash ==========");
    printf("Signal:%d\n",sig);
    if(symbols)
    {
        for(int i=0;i<size;i++)
        {
            printf("%s\n",symbols[i]);
        }
        free(symbols);
    }
    fflush(stdout);
    //恢复默认异常处理
    signal(sig,SIG_DFL);
    //重新触发异常，生成core文件
    raise(sig);
}
#endif
```
```cpp
#ifndef _WIN32
	signal(SIGSEGV,ApplicationCrashHandler);
	signal(SIGABRT,ApplicationCrashHandler);
	signal(SIGFPE,ApplicationCrashHandler);
	signal(SIGBUS,ApplicationCrashHandler);
#endif
```

# 4. Core Dump配置-使用前
## 4.1 开启Core文件生成
查看：
```bash
ulimit -c
```
设置：
```bash
ulimit -c unlimited
```
## 4.2 修改Core文件名称

打开
```bash
nano ~/.bashrc
```
添加，保存退出
```
ulimit -c unlimited
```

打开：
```bash
sudo nano /etc/sysctl.d/99-core-dump.conf
```
添加，保存退出
```bash
kernel.core_pattern=core.%e.%p
```
```bash
sudo nano /etc/security/limits.d/core.conf
```
添加，保存退出
```bash
* soft core unlimited
* hard core unlimited
```
```bash
sudo sh -c 'echo "core.%e.%p" > /proc/sys/kernel/core_pattern'
```

core单独文件放置 
```bash
sudo mkdir -p /路径/HIDCamera
sudo sh -c 'echo "/路径/HIDCamera/core.%e.%p" > /proc/sys/kernel/core_pattern'

```
# 6. 崩溃测试结果
运行：
```bash
./HIDCamera_Qt6
```
输出：
```text
========== Application Crash ==========
Signal:11
./HIDCamera_Qt6(+0x130af9)
./HIDCamera_Qt6(+0x1713b9)
Segmentation fault (core dumped)
```
生成文件：
```text
core.HIDCamera_Qt6.xxxxx
```
# 7. GDB使用方式

加载：
```bash
gdb ./HIDCamera_Qt6 core.HIDCamera_Qt6.xxxxx
```
查看调用栈：
```gdb
bt
```
查看所有线程：
```gdb
thread apply all bt
```
查看源码：
```gdb
list
```
查看变量：
```gdb
print xxx
```
